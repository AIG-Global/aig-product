# Core 10 Applications

**AIGINVEST's focused product strategy**

---

## The Principle

Not dozens of features trying to be everything.

**Ten core applications** that every user understands immediately.

Everything else is a **Marketplace app** or **future capability**.

This discipline keeps the product focused and coherent.

---

## The Core 10

### 1. **Diana** — AI Operating System

**What it does:** Orchestrates your work through conversation.

**Key Features:**
- Understand your intent
- Remember your context
- Create environments (workspaces)
- Take action (create projects, documents, tasks)
- Guide next steps

**Why it's core:** Diana is the entry point. Everything flows through Diana.

**Success metric:** User can manage their entire workspace using only Diana (no clicking).

---

### 2. **Workspace** — Your Working Environment

**What it does:** Home base for organized work.

**Key Features:**
- Organize projects, documents, tasks
- Share with team members
- Configure permissions
- Customize settings
- View workspace overview

**Why it's core:** Every user needs a place to organize. Workspace is that place.

**Success metric:** Workspace becomes sticky (user's "home" in AIGINVEST).

---

### 3. **Projects** — Organize Work Into Projects

**What it does:** Group related work together.

**Key Features:**
- Create project
- Add members
- Link documents and tasks
- Set status (planning, active, completed)
- View project overview

**Why it's core:** Projects are the natural unit of work organization.

**Success metric:** Teams use projects to organize sprints/initiatives.

---

### 4. **Documents** — Create and Manage Content

**What it does:** Rich-text document editor with AI assistance.

**Key Features:**
- Create and edit documents
- AI-assisted writing (generate, edit, refine)
- Template library
- Version history
- Sharing and permissions
- Export to PDF/Word

**Why it's core:** Documents are output. Most work ends up here.

**Success metric:** Documents created via Diana and edited by users.

---

### 5. **Tasks** — Track What Needs Doing

**What it does:** Simple, powerful task management.

**Key Features:**
- Create task
- Set priority (low/medium/high)
- Set status (todo/in_progress/done)
- Assign to team member
- Set due date
- Kanban board view
- List view

**Why it's core:** Users need to track work. Tasks is that system.

**Success metric:** Teams use Tasks for sprint management.

---

### 6. **Calendar** — Schedule and Timeline

**What it does:** View your schedule and project timeline.

**Key Features:**
- Personal calendar (integrates with Google/Outlook)
- Project timeline (Gantt view)
- Team member availability
- Meeting scheduling
- Deadline tracking

**Why it's core:** Every user has a calendar. Synchronizing with AIGINVEST is natural.

**Success metric:** Calendar becomes source of truth for deadlines.

---

### 7. **Knowledge** — Build Your Knowledge Base

**What it does:** Curate and organize knowledge for your team.

**Key Features:**
- Create topic (wiki-style pages)
- Link topics (create knowledge graph)
- Search across topics
- Tagging and categorization
- Usage analytics

**Why it's core:** Teams accumulate knowledge. Knowledge base preserves it.

**Success metric:** Teams use Knowledge as internal reference library.

---

### 8. **Marketplace** — Install Skills and Integrations

**What it does:** Extend AIGINVEST with skills, integrations, templates.

**Key Features:**
- Browse skills and integrations
- Install with one click
- Manage installed skills
- Rate and review
- Creator earnings

**Why it's core:** Extensibility is how platforms scale. Marketplace enables it.

**Success metric:** 10%+ of users install at least one marketplace app.

---

### 9. **Settings** — Configure Workspace

**What it does:** Control how your workspace behaves.

**Key Features:**
- Personal preferences (theme, language, notifications)
- Workspace settings (visibility, collaboration defaults)
- Team member management
- Integration configuration
- Billing (if applicable)

**Why it's core:** Every user needs to configure their environment.

**Success metric:** Settings used by 100% of users (at least once).

---

### 10. **Profile** — Your Account and Preferences

**What it does:** Manage your AIGINVEST account.

**Key Features:**
- Edit profile (name, avatar, bio)
- Manage API keys
- View account activity
- Connected accounts (Google, GitHub)
- Privacy settings
- Account deletion

**Why it's core:** Every user has an account. Profile is the interface.

**Success metric:** Profile feels personalized.

---

## What's NOT Core 10

These are **Marketplace apps** or **future capabilities**, not core:

- ❌ CRM (Business Cloud → Marketplace)
- ❌ ERP (Business Cloud → Marketplace)
- ❌ HR Tools (Business Cloud → Marketplace)
- ❌ Finance Tracking (Business Cloud → Marketplace)
- ❌ Video Conferencing (Integration → Marketplace)
- ❌ Slack Integration (Integration → Marketplace)
- ❌ GitHub Integration (Integration → Marketplace)
- ❌ Analytics Dashboard (Marketplace)
- ❌ Forms Builder (Marketplace)
- ❌ Email Templates (Marketplace)

These are **powerful capabilities**, but not **core products**.

They come after we perfect the Core 10.

## Why This Strategy Works

### For Users
- **Focus:** Not overwhelmed by 50 features
- **Clarity:** Know what each app does
- **Mastery:** Can become proficient quickly
- **Extensibility:** Can add more when ready

### For Development
- **Priority:** Know what to build first
- **Velocity:** Small focused app = faster shipping
- **Quality:** Fewer features = more polish
- **Maintenance:** Core apps extremely stable

### For AIGINVEST
- **Positioning:** "Best AI workspace" (not "has everything")
- **Differentiation:** Diana + orchestration unique
- **Defensibility:** Marketplace ecosystem defensible
- **Scaling:** Can add Business Cloud later without rewriting

### For Investors
- **Strategy:** Clear phase 1 → phase 2 → phase 3
- **Scope:** Focused, not scattered
- **Timeline:** Core 10 shippable in ~5 months
- **Expansion:** Natural path to Business Cloud
- **Moat:** Knowledge graph + orchestration defensible

## The Rule Going Forward

**New feature request?**

Ask: "Which Core 10 app does it belong in?"

If the answer is "none of them," it's a **Marketplace app**, not core.

If it doesn't fit Core 10, it comes after Core 10 is solid.

This discipline prevents feature creep and keeps the product focused.

---

## Example: "Can we add video conferencing?"

**Answer:** Yes, but as a Marketplace app, not core.

**Why:**
- Not unique to our market (Slack, Zoom already do this)
- Integration > native build
- Let marketplace builders compete
- Core 10 is our differentiator (Diana + Workspace)

**When:** After Core 10 is shipped and stable (Sprint 8+)

This is how we stay fast.

This is how we build something great.
