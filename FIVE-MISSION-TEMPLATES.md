# Five Mission Templates

**The Starter Portfolio: Launch AIGINVEST with Five Polished Missions**

**Date:** 2026-07-06  
**Status:** Mission Portfolio Specification  

---

## Strategy

Instead of launching 50 half-finished features, AIGINVEST launches with 5 polished mission templates that cover the broadest range of real user needs.

These five missions:
- ✅ Cover 80% of initial use cases
- ✅ Demonstrate the Core 10 apps in action
- ✅ Show the power of Diana's orchestration
- ✅ Are deep, not shallow
- ✅ Can be customized for infinite variations

## How the Five Missions Work Together

### Coverage

```
Template 1: Build a Startup
  → Covers entrepreneurs, builders, risk-takers
  → Average engagement: 14 weeks, then repeat with new idea

Template 2: Learn Something
  → Covers students, professionals, learners
  → Repeatable (different topics, same template)
  → Average engagement: 8 weeks per topic

Template 3: Manage My Business
  → Covers managers, executives, small business owners
  → Ongoing (stickiest mission)
  → Engagement: 365 days/year

Template 4: Write a Book
  → Covers authors, thought leaders, storytellers
  → High aspiration, high satisfaction
  → Average engagement: 10 weeks, high completion

Template 5: Personal Productivity
  → Covers everyone
  → Ongoing (most accessible)
  → Engagement: Every day
```

### User Flows

```
Flow 1: The Entrepreneur
  Onboard → Build a Startup → Personal Productivity (daily)
  After startup: Learn Something (upskilling)
  Future: Manage My Business (when scaling)

Flow 2: The Employee
  Onboard → Personal Productivity (ongoing)
  Side interest: Learn Something (2-3x/year)
  Aspiration: Build a Startup (someday)

Flow 3: The Creator
  Onboard → Write a Book
  Then: Personal Productivity (daily)
  Learning: Learn Something (topic-specific)

Flow 4: The Executive
  Onboard → Manage My Business (ongoing)
  Development: Learn Something (leadership topics)
  Thought leadership: Write a Book (thought leadership)

Flow 5: The Lifelong Learner
  Onboard → Learn Something (ongoing)
  Personal: Personal Productivity (daily)
  Aspiration: Build a Startup or Write a Book
```

### Cross-Template Learning

```
A user in "Build a Startup" might:
  - Use "Learn Something" for market research
  - Use "Personal Productivity" for daily execution
  - Reference "Write a Book" for pitch narrative
  
All templates share:
  - Same Diana intelligence
  - Same documents/tasks infrastructure
  - Same Knowledge Graph
  - Same team collaboration
  - Same AI guidance system
```
